# DRR/DRVM reproducibility materials

This folder supports the companion manuscript on continuous validity
monitoring of frozen prediction-to-decision representations.

## Included artifacts

- `FAME_DRVM_final_validation_v8.ipynb`
  - null audit;
  - finite-horizon power and delay;
  - first-order monitorability calculations.

- `FAME_DRVM_real_applications_v10.ipynb`
  - fantasy-football historical deployment replay;
  - Energy historical deployment replays;
  - episode-level DRR/DRVM trajectories.

- `FAME_DRVM_temporal_robustness_v12.ipynb`
  - predictable-heteroskedastic stress test;
  - seasonal reference misspecification;
  - contextual-reference comparison;
  - baseline-uplift sensitivity.

- `mc_results_v8.zip`
- `results_drvm_real_v10.zip`
- `results_drvm_temporal_robustness_v12.zip`

## Scope

These artifacts do not reproduce the companion FAME/DOC temporal-transfer
tables. They support post-freeze monitoring claims only.
