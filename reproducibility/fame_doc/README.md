# FAME/DOC temporal-transferability reproducibility materials

This folder supports the companion manuscript on learning, calibration, and
temporal transferability of prediction-to-decision representations.

## Included notebooks

- `FAME_IJDSA_v11_1_CORRIGIDO_FINAL.ipynb`
- `FAME_DOC_02_calibracao_teste_KBS_v4_1_ablation_corrigido.ipynb`
- `FAME_temporal_replication_H2_2021_2022_2023_2024.ipynb`
- `FAME_Energy_05_v2.1_DOC_Calibration_i7_12700K.ipynb`
- `FAME_Energy_TemporalReplication_v3.2_RobustnessMargins.ipynb`

The existing repository/Zenodo transfer archive should remain the authoritative
source for the processed transfer outputs, frozen parameters, temporal split
definitions, and audit artifacts already released with v1.0.2.

## Scope

These artifacts do not contain DRR/DRVM monitoring theory or monitoring replay
results. They support FAME/DOC calibration and temporal-transferability claims.
