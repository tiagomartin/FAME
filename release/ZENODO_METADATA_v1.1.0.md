## Description

Version 1.1.0 of the FAME reproducibility archive. This release organizes the
project into two companion research tracks:

1. FAME/DOC temporal transferability of learned prediction-to-decision
   representations in predictive-prescriptive systems;
2. DRR/DRVM post-deployment validity monitoring of frozen
   prediction-to-decision representations.

The release adds controlled DRVM Monte Carlo validation, historical
fantasy-football and Energy deployment replays, temporal reference-risk stress
tests, baseline-uplift sensitivity outputs, manuscript-specific reproducibility
maps, and explicit documentation of the scientific non-overlap between the two
companion studies.

The release preserves the v1.0.2 temporal-transfer artifacts and the existing
reproducibility boundaries for non-redistributed third-party raw data.
